지금까지 이번 세션에서 한 작업을 다음 세션이 바로 이어받을 수 있게 정리해줘.
코드는 건드리지 말고 아래 항목만 간결하게 정리:

1. 이번에 실제로 구현/수정한 것 — 파일:라인 단위로, 한 줄씩
2. 아직 안 된 것 (TODO)
3. 이번에 새로 합의한 규칙·제약 — CLAUDE.md §1~§5 중 새로 정해진 것이 있다면
   구체적으로 (경계, 계약, 위험 작업 기준 등)
4. §4(종단 검증) 기준으로 실제로 확인한 것 / 아직 확인 못 한 것
5. 다음 세션에서 결정해야 할 열린 질문

`git status`, `git diff`로 실제 변경 파일을 먼저 확인한 뒤 정리해.

!git status
!git diff --stat HEAD
