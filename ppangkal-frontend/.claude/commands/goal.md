다음 목표를 착수 전에 짧게(3~5줄) 정리해줘. 코드는 아직 건드리지 말고,
목표 자체가 애매할 때만 질문 1개로 좁혀줘. CLAUDE.md §2 형식대로:

1. 어느 영역 작업인가 (CLAUDE.md §1 경계 기준 — lib/screens, lib/services,
   lib/models, pubspec.yaml 등 어디를 건드리는지)
2. 대상이 되는 구체적 파일/함수/엔드포인트
3. 완료 기준(DoD): 어떤 입력 → 어떤 동작 → 어떤 관찰 가능한 결과로 성공을
   판단할지 (타입 통과가 아니라 실제 확인 가능한 형태로, `/verify`로 나중에 확인)
4. 건드리면 다른 부분이 깨질 수 있는 지점(리스크)

목표: $ARGUMENTS
